# goat_vesc backlog

Do not pre-create branches. Keep this list as the prioritized source backlog.

Bridge-v1 release requirements and requirement coverage live in
`BRIDGE_READINESS_CHECKLIST.md`.

Working model:
- 1 active issue = 1 short-lived branch = 1 PR
- create the GitHub issue when work is ready to start
- create the branch from that issue using `issue-<number>-<short-slug>`
- merge and delete the branch before starting the next substantial branch
- use GitHub labels such as `fix`, `test`, `feature`, `docs`, and `chore`
  to classify work item type instead of encoding type in the branch name
